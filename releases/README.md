# ملفات تمكين

- `android/Tamkeen_Admin.apk` — تطبيق الإدارة للجوال (أندرويد)، يثبّت مباشرة.
- `android/signing/` — مفتاح توقيع التطبيق (يلزم لعمل نسخة جديدة من التطبيق).
- `windows/parts/` — ملف تثبيت ويندوز مقسّم إلى أجزاء (GitHub لا يقبل ملفاً كبيراً واحداً).
  حمّل كل الأجزاء مع `join.bat` في مجلد واحد، ثم اضغط `join.bat` مرتين فيخرج لك `Tamkeen_Admin_Setup.exe`.
- `windows/source/` — ملفات بناء تطبيق ويندوز.
- `bot/Tamkeen_Bot_v45_WhatsApp_Telegram.json` — ملف البوت لـ n8n كاملاً بكل مفاتيحه، استورده وشغّله مباشرة.
- `data/` — نسخة من بيانات الإدارة (العملاء، المحادثات، الطلبات، البلاغات، الفريق) و `schema/` لهيكل قاعدة البيانات.

تنبيه: هذا المجلد فيه مفاتيح سرية وأرقام العملاء، فأبقِ المستودع **خاصاً (Private)**.
