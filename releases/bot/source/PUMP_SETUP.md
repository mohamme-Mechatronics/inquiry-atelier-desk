# مسار الغطاسات — تمكين v46

المسار: طلب عرض سعر ← غطاسات وآبار زراعية ← اسم المزارع ← الموقع ← وحدة القدرة والقدرة ← الفازات والجهد ← التيار المقنن ← عمق تركيب الغطاس ← الارتفاع الديناميكي TDH ← التدفق المطلوب ← ساعات التشغيل ← مصدر التشغيل ← طول كابل المحرك.

بعدها يختار البوت منظومة معتمدة ومتوافقة من الأصناف والأسعار. ينتقل إلى عرض السعر الرسمي PDF ثم متابعة الشراء أو تعديل المنظومة أو طلب معاينة مهندس. التعديل يعيد التحقق من التوافق ويصدر نسخة جديدة للعرض قبل التسديد.

التسديد يستخدم المسارات الحالية: حوالة محلية، محفظة إلكترونية، أو الدفع عند الاستلام. إشعار الحوالة يُسجل في الطلبات للمراجعة؛ **لا يعتبر إثبات تسديد تلقائياً**. موظف الحسابات يتحقق من الحوالة من الإدارة، ولا يعتمد زر العميل كدليل دفع.

طلبات المراجعة والمعاينة تظهر تحت «زراعي / غطاسات» بدون مبلغ مختلق. عروض الأسعار والتسديد تُسجل برقم العرض، ويحدَّث نفس الطلب عند وصول الإشعار.

## المتبقي لتفعيل عروض فعلية

لا يوجد في الكتالوج الحالي سعر أو موديل إنفرتر غطاسات معتمد، ولا جدول توافق هندسي. لذلك المسار يجمع البيانات ويُحيلها للإدارة، ولا يطلب تحويل مبلغ قبل وجود منظومة معتمدة.

يلزم اعتماد مهندس للمضخة ومنحنى التشغيل ومجال دخل DC وMPPT وجهد الدائرة المفتوحة في البرد والسلاسل والتوصيل وتيار المحرك والحمايات والجفاف والتأريض وفلاتر خرج VFD ومقاس الكابل وطوله والأنابيب والتدفق. قدرة الحصان أو عمق البئر وحدهما لا يكفيان. التشغيل الليلي يُحال للمراجعة ولا يضيف بطاريات تلقائياً.

## إضافة منظومة معتمدة من الأصناف والأسعار

1. أضف الموديلات الفعلية وأسعارها إلى الكتالوج؛ لا تستخدم أمثلة الاختبار كأسعار للبيع.
2. أضف صنفاً يبدأ رمزه بـ `PUMP_PACKAGE_` واسم المنظومة. السعر الخاص بهذا الصنف لا يستخدم؛ الإجمالي يُحسب من مكوناته.
3. أضف في المواصفات سطراً واحداً يبدأ بـ `PUMP_CONFIG=` يتبعه JSON مطابق للحقول التالية، يعبئه المهندس بعد اعتماد المنظومة:

```text
approved: true عند الاعتماد الفعلي فقط
approvalRef: رقم الاعتماد الهندسي
validUntil: آخر يوم صلاحية بصيغة YYYY-MM-DD
voltage / phase: جهد المحرك وعدد الفازات
minMotorKw / maxMotorKw: مجال قدرة المحرك بالكيلووات
minCurrent / maxCurrent: مجال التيار المقنن بالأمبير
minHead / maxHead: مجال TDH بالمتر
minFlow / maxFlow: مجال التدفق بالمتر المكعب/ساعة
maxDepth: أقصى عمق تركيب معتمد
maxCable: أقصى طول كابل معتمد
maxHours: ساعات التشغيل المعتمدة للموقع
sources: ["1"] للنهاري أو ["1","2"] إذا كان احتياط الشبكة/المولد معتمداً
bom: قائمة {code: رمز صنف فعلي, qty: الكمية, role: وظيفة الصنف}
```

وظائف المكونات المطلوبة: `panel`, `vfd`, `dc_protection`, `motor_protection`, `cable`, `earthing`, `installation`. يجب أن تكون جميع المكونات موجودة ولها سعر موجب ومواصفات فعلية. لا يقبل المسار بطاريات أو معدات تخزين بدلاً من VFD.

**الأسعار والموديلات وقيم التوافق غير مضافة عمداً حتى اعتمادها.** أمثلة الاختبار وهمية ومعزولة ولا تُضاف للكتالوج.
